# بُرهان — ENG0023 Engineering Drawings and Model

## تشغيل المشروع
1. ضع `index.html` و`script.js` و`style.css` في مجلد واحد.
2. احتفظ بمجلد `assets` كاملًا بجانب هذه الملفات.
3. ضع شعارك `Logo.Brhan.png` في المجلد الرئيسي نفسه، بجانب `index.html` (وليس داخل `assets`).
4. افتح `index.html` في المتصفح، أو استخدم Live Server في Visual Studio Code.

## المزايا
- تصميم متجاوب للهواتف والأجهزة اللوحية واللابتوبات.
- بنك مختصر ومنقّح يركّز على الأفكار المختلفة بدل تكرار السؤال نفسه.
- أسئلة وخيارات باللغة الإنجليزية، وإعدادات وتنقل باللغة العربية.
- اختيار مدة الاختبار قبل البدء، بما في ذلك خيار إجراء الاختبار دون مؤقت.
- تنقل حر بين الأسئلة باستخدام شريط الأرقام في أسفل الاختبار؛ اللون الأخضر يعني تمت الإجابة، والرمادي يعني لم تتم الإجابة، والإطار الأزرق يحدد السؤال الحالي.
- ثلاثة أسئلة إسقاط بصري تعرض مجسمًا منظورًا وخيارات مساقط مرسومة منفصلة A/B/C، دون تعليم الإجابة الصحيحة على الرسم.
- تمارين رسم على الورق لا تُصحّح آليًا.
- مراجعة النتائج مع الشرح بالإنجليزية والعربية واسم الفصل والموضوع واسم ملف المصدر.

## بنك الأسئلة الحالي
يتضمن المشروع الفصول الأربعة المتاحة حاليًا. العدد يتحدّث تلقائيًا من قاعدة الأسئلة في `script.js`. صُممت بعض الرسومات النظيفة خصيصًا للتدريب على مفاهيم الإسقاط الموجودة في الفصل الثالث، بينما تستخدم تمارين الرسم المحددة صفحات التمارين المرفقة.

## ملاحظة
تحتاج تمارين الرسم الورقية إلى مراجعة الطالب أو المدرس؛ الضغط على «أتممت الرسم» يسجل إنجاز التمرين فقط ولا يعني أن الرسم صُحح آليًا.
